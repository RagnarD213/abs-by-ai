The source archive's Drive-copy status and hash receipt are kept in `source-mirror-status.json` beside its source register; the usable-library mirror verification does not substitute for that separate check.

A source file's presence in this archive does not override a rejection, approve an exercise demonstration, or permit a faulty section in an edit. Editors use the main catalog for cleared reusable assets and the source register to trace or review an original.
