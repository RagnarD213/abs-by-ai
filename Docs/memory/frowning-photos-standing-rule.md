Don't use a photo where Dan is frowning, scowling, or has a sullen/unhappy resting expression
as a thumbnail or cover image by default. Only use one if Dan specifically asks for it, or the
video/post is itself about something sad, negative, or a failure/bad event.

**Why:** Dan flagged the live "The 17 Dollar Ab Wheel Beats Every Crunch" YouTube thumbnail,
which used `studio-blue-271` (red "THAI BOXING" shorts photo) — his mouth is visibly downturned
and sullen, the wrong tone for an upbeat "do this" thumbnail.

**How to apply:** Every genuinely frowning finalized photo is sorted into
`photos/finalized social media photos/Frowning Photos/` in the Abs By AI project so it isn't
picked by default when browsing or building a new thumbnail (both `_FINAL_PRIMARY.jpg` and
`-IG-4x5.jpg`; the `_cutouts/*_CUTOUT.png` stayed in place for on-demand reuse). As of
2026-09-13: `studio-blue-271`, `photo-20`, `studio-blue-47`, `studio-white-2`, `studio-gray-63`,
`photo-81`, `photo-84`, `photo-135`, `photo-137`, `photo-138`, `photo-158`.

The bar is a real downturned/scowling mouth, not merely "not smiling" — serious/intense-focus
photos (flexed poses, martial-arts stances) stay in the main folder since a stern look is a
normal fitness-brand vibe, distinct from a frown. Full rule text and the list is in `AGENTS.md`
under "Don't default to frowning photos" — check there before pulling a photo for a new
thumbnail if its expression looks borderline. Related: [[before-after-same-person]].
