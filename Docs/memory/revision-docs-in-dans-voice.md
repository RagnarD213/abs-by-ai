Every revision document for a freelance editor (Zeeshan, Waleed, Muhammad, anyone) is written in first person as Dan, and nothing in it may say or imply that Claude did the review or added items. No "Claude's additions" headers, no "reviewed by Claude" lines. When Dan has typed a few items himself before asking for the rest, rewrite his items into the same voice and format as the rest so the doc reads as one list from one author.

**Why:** Dan said so on 2026-09-02 after a round-2 ab-wheel doc was appended under a "Claude's additions" header. The editor is meant to believe Dan personally made every revision; a visible split undermines that.

**How to apply:** Applies to the Google Doc, the markdown copy in `revision docs/`, and section headers. Merge, don't append. See [[handoff-starter-prompt-rule]] for the other standing delivery rule on handoffs.
