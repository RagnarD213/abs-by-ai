Dan expects over 80% of visitors to be on mobile. For every website brief, design task and review gallery (Claude, Codex, Gemini, Grokbot alike):
- Design each page on the phone first. Settle the first screen, the product image, the order of information, the navigation and the main action at phone width (390px for SixPackAbs).
- Then adapt that phone design to desktop (1440px). The phone order is the source of the desktop order.
- Every review, export and copy map opens on the phone design, or shows phone and desktop together with phone first and large enough to read.
- If a board was composed desktop first, revisit the phone composition before delivering.

**Why:** Dan, 2026-11-04, while reviewing the SixPackAbs shop boards: "he expects over 80% of visitors to be on mobile."
**How to apply:** any website, landing page, cart or shop design and its galleries. Also in AGENTS.md ("Website design: phone first"). Related: [[sixpackabs-shop-design-direction]], [[design-quality-lessons]].
