Dan, 2026-10-01, approving the kit-built Ad 8 verticals: "going forward, I don't want to see anything else with these
old graphics. This is fine for this one... I want everything going forward to be made with soft blue lights and
hyperframes in the review process in the first round."

**Why:** the olive card / black lower-third look is Muhammad's old style; Dan has locked Soft Blue Light as the
graphics standard and approved the HyperFrames templates ([[hyperframes-decision]]).

**How to apply:**
- Every new edit, vertical, cutdown or rebuild gets Soft Blue Light graphics built with HyperFrames, and they are in
  the FIRST review packet (not added in a later round). See [[graphic-lock-and-ai-frames-first]] and
  [[review-page-what-i-decided]].
- The vertical kit ([[vertical-kit-autofill]]) still draws the old olive graphics (`vlib.py`). Before the next
  vertical is built with it, its graphics layer has to be ported to the Soft Blue Light HyperFrames templates. A
  vertical that reproduces an editor's old-style master is no longer acceptable as-is.
- Already approved or delivered files are not rebuilt (Ad 8 verticals were approved with the old look).
