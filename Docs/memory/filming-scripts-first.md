A script written into a shoot doc is a **filming script**, not a teleprompter script. Wherever a graphic, photo, B-roll
shot, on-screen text, clip or editor instruction belongs, it goes in as its own line in brackets and ALL CAPS, before the
words it covers. The clean teleprompter-only copy is a separate, later job (`/teleprompterscripts`).

**Why:** on 2026-10-06, during batch D of the 10/17 shoot scripts (Clavicular reaction shorts), the first version carried
only a clip cue and one or two notes per script and labelled itself "Teleprompter script". Dan, mid-task: "I want these
all to be filming scripts, which means they should have the notes in all caps and brackets where we're putting in a
graphic or we need a note for the editor. We'll make teleprompter scripts in the next specs."

**How to apply:** for every script in a shoot doc, cue each beat: the opening shot, the clip (range plus lower third),
before pictures (his standing photo rules), full screen graphics with the exact words and numbers, on-screen text,
B-roll with whether it exists or must be filmed, and the closing on-screen URL. No drug or brand name in on-screen text.
Label the note line "Filming script". Spoken words do not change. My reading, not his words: this replaces the older
"cue density: LIGHT" default in `/scriptfromoutline` for shoot docs. Related: [[script-zero-edit-lessons]],
[[dan-personal-facts-for-scripts]].
