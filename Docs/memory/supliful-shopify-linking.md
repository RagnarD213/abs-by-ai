Supliful fulfills only products **published from Supliful to Shopify**. Products made directly in Shopify cannot be linked by SKU or location (Supliful support, 2026-11-05). Multipacks (3 and 6 tubs) must be **Supliful Single SKU bundles** (My Products > Create Bundle), each its own Shopify product. Shopify variants alone do not set fulfillment quantities.

**Why:** the first SixPackAbs Shopify products were hand-made and would not have fulfilled; creatine was rebuilt through Supliful on 2026-11-05. The other five products (Great Again T, Eternal Burn AM/PM, Carb Curber, Z Shred Support) are still hand-made in Shopify and need the same rebuild before launch.

**How to apply:** publish from Supliful, then edit in Shopify (add photos, collections, option, subscription). After publishing, set Supliful retail price first. Shopify Combined Listings is Plus-only, so one page for several packs needs theme links between products. Subscription plans attach to the single-unit product.
