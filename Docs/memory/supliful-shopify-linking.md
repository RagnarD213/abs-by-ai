Supliful fulfills only products **published from Supliful to Shopify**. Products made directly in Shopify cannot be linked by SKU or location (Supliful support, 2026-11-05). Multipacks (3 and 6 tubs) must be **Supliful Single SKU bundles** (My Products > Create Bundle), each its own Shopify product. Shopify variants alone do not set fulfillment quantities.

**Why:** the first SixPackAbs Shopify products were hand-made and would not have fulfilled; all six (creatine, Great Again T, Eternal Burn AM/PM, Carb Curber, Z Shred Support) were rebuilt through Supliful on 2026-11-05, with 3- and 6-packs as bundles. Old hand-made versions are Draft (`<handle>-old-draft`).

**How to apply:** publish from Supliful, then edit in Shopify (add photos, collections, option, subscription). After publishing, set Supliful retail price first. Rename the old Shopify product's handle (and delete the auto-redirect) before publishing so the new product gets the clean handle. Shopify saves on these pages are slow (10 s+); wait before navigating or the edit is lost. Supliful's bundle description is long generic copy, so replace it with the approved short copy. Shopify Combined Listings is Plus-only, so one page for several packs needs theme links between products. Subscription plans attach to the single-unit product.
