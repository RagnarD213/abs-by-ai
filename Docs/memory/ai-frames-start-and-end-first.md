Every AI clip idea first reaches Dan as a complete START and END pair; when two versions are made (Codex and Google blind test), two complete pairs, each END made on its own START's model, shown unlabeled.

**Why:** Dan, 2026-11-05 (RO-15 round 1): "It's hard for me to judge which start frame to use from the start frame alone... Sometimes I would choose the start frame, but the end frame doesn't turn out good, so I need to see start and end frames for all these images you're generating going forward in the first step."

**How to apply:** frame spec, gate and a fresh frame-reviewer on every pair before the page; budget two frames and two reviews per version. Replaces the RO-31 "START only in round 1" shortcut. Rule lives at the top of VIDEO-RULES.md. Related: [[blind-google-vs-codex-images]].
