When Dan names a piece of equipment, a food or a product in a line, the clip over that line must show him using that very thing. The right exercise without the named object is the wrong clip.

**Why:** Dan, finalizing RO-06 on 2026-10-10: "if I reference the medicine ball, it'd be better to show something where I'm using the medicine ball rather than something unrelated." The film showed lying toe touches with no ball (clip B0467) over "I prefer the medicine ball though". He kept it as is and did not want another round over it; it is for future edits.

**How to apply:** for every cutaway, read the sentence it covers, write down the object named, and search the clip library for that object plus the exercise. Re-check when a cutaway is moved or lengthened (that one had been started earlier to cover something else). Scope (my reading): every video and every revision doc for an editor.
