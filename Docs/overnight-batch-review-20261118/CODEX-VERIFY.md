## New defects in this commit

- **High — An interrupted repair can deliver a different cut after resume.** A repair writes valid costs, changes FAIL to PASS and points delivery at an earlier export with a current PASS stamp. It then hits its allowance before writing the candidate marker. The next claim sees zero format errors and sends the earlier cut to review without checking the original fingerprint, exit or marker. Reproduced with the real delivery validator and stamp reader and a fixture reviewer. **Smallest fix.** Persist a successful repair only after checking exit, marker and fingerprint. On resume, retry an unaccepted repair against the original submission or block it. Always compare the fingerprint before advancing. `scripts/edit-queue/batch_runner.py:283–321`
- **High — An untested mount can count as passed.** Extreme is skipped while absent and saved with `passed=true`, `mounted=false` and no probe steps. Attach it at the same path before status is evaluated and the skipped record satisfies the now-required folder, even under the matching request ID. Reproduced with a simulated mount transition. **Smallest fix.** Record a separate skipped result and require a successful write, rename and delete at the current resolved path and volume identity for every required folder. `scripts/edit-queue/batch.py:390–406`, `scripts/edit-queue/batch.py:490–500`
- **High — The deadline leaves new volume lookups unbounded in the dispatcher.** With a recent cached result and an SMB mount that now stalls, `ismount` or `realpath` can hang in `launchd_probe_status()` even if the probe child times out. The tick then misses reconciliation and the report. **Smallest fix.** Evaluate live mount and resolved-path checks inside the bounded worker and treat its timeout as a failed check. `scripts/edit-queue/batch.py:383–392`, `scripts/edit-queue/batch.py:445–457`, `scripts/edit-queue/batch.py:485–496`, `scripts/edit-queue/batch.py:914–928`
- **High — Probe cleanup can remove unrelated files.** The fixed directory is accepted if it is a symlink to a directory, and the cleanup unlinks every entry it finds. If the fixed name is a symlink to an existing folder with review files, a routine probe can remove those files. Two Macs probing a shared folder can also remove each other’s probe files. **Smallest fix.** Give each Mac its own probe directory, refuse symlinks and limit cleanup to the two owned probe filenames. `scripts/edit-queue/batch.py:411–421`
- **Medium — The M6 can falsely report that healthy M2 work is stopped.** A timeout in M6’s local slot-status command falls into the same handler as an M2 connection failure. The M6 labels the ledger unreachable and reports every cached queued round as stopped, including M2-pinned rows M2 can still claim. **Smallest fix.** Handle local tick errors separately and scope an M6 fault to M6. For a real coordinator connection failure, show stale M2 state as unknown and mark M6 claims unavailable. `scripts/edit-queue/batch.py:710–712`, `scripts/edit-queue/batch.py:725–728`, `scripts/edit-queue/batch.py:930–955`
- **Medium — The newly suggested takeover can act on the wrong round.** After R1 hits three start failures, the saved instruction tells Dan’s chat to take over by job ID. If R2 is subsequently registered, following R1’s instruction takes over R2 because takeover selects the newest round. **Smallest fix.** Include the batch and round key in the action and use them to select the exact ledger row. `scripts/edit-queue/batch.py:129–133`, `scripts/edit-queue/batch.py:263–276`, `scripts/edit-queue/batch.py:304–305`
- **Medium — A new start incident can be silently seeded.** On a clean install with no alert ledger, the first stopped row is recorded as previously announced even though there was no previous alert. It never rings until it clears and recurs. Reproduced with a blank ledger. **Smallest fix.** Seed only rows covered by a known prior sent incident or a recorded migration baseline. A missing ledger should send the first live incident. `scripts/edit-queue/batch.py:853–873`
- **Medium — The new offline fixture can kick the real local LaunchAgent.** The fixture replaces SSH through PATH, but the child calls the real `b.kick()`, which invokes local `launchctl` before using the SSH shim. On a Mac with the agent installed, running the test can trigger a production tick. **Smallest fix.** Stub the entire kick in the child and record fixture calls without using launchctl or SSH. `scripts/edit-queue/tests/test_batch_repairs.py:241–257`, `scripts/edit-queue/batch.py:545–554`
- **Low — A resumed repair is charged twice for prior edit time when calculating its timeout.** With a two-hour job and one hour already recorded, the setup gives the resumed claim one hour, then the repair subtracts that same hour again and gets only the 15-minute floor. **Smallest fix.** Subtract only time used in the current claim from the already-adjusted budget. `scripts/edit-queue/batch_runner.py:211–214`, `scripts/edit-queue/batch_runner.py:301–305`
- **Low — A periodic probe reactivates the last completed request.** After request A has been answered, the next timed probe overwrites the record with a null request. The following tick treats A as pending and performs a second full probe. **Smallest fix.** Preserve the last answered ID separately or consume the matching request after recording its result. `scripts/edit-queue/batch.py:462–481`
