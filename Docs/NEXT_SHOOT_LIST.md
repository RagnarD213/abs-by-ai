## Standing setup notes for whoever runs the shoot

- Framing is hair anchored: top of frame locks to the top of the hair, NEAR or FAR only, never
  wide. See memory `framing-standard-hair-anchored`.
- Two microphones. The good lav track is chosen per file afterwards, so record both and do not
  try to pick on set.
- Demonstration inserts get filmed with space around you so vertical crops have somewhere to go.
