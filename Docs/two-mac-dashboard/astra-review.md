Even with both reachable, placement requires job-specific ownership, fresh local storage, outstanding commitments and compatible waiters. The generic `decide()` omits several of these checks. If one Mac is unavailable, show the other Mac’s figures and “Check status before starting.” When a slot appears available, say **“Room for one new edit on M2. Use normal routing to start it.”** Use this qualified wording only when shared and local state, health and a suitable storage basis support it. Otherwise show the observed slot separately and explain the missing check. Never turn a cached external-drive reading into clearance to start. 2. **Observe recorded work without taking scheduler locks.** `editcap._load()` renames corrupt files, `editroute.state_dir()` writes a probe, `hostcfg.idle_seconds()` writes a cache, `renderq.mem_state()` writes samples, and the lock checker can create files or briefly take the scheduler’s exclusive lock. Read bounded files directly. A render slot’s `start` is the step start, not a stored process birth identity. An unended record, a live PID of the same number, or an old ticket filename alone cannot prove a live holder. If evidence disagrees, label the step unconfirmed and retain conservative capacity.
