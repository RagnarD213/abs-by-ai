## How to run it (all of this is in `/photo-edit` — the load-bearing bits called out)

1. **BODY (BALANCED DEFINITION PASS) is canonical** — the house standard Dan locked on batch-4 rev 2
   ("You've got it perfected with the abs… This is the perfect balance"). No bake-off, straight to
   `--tier final` (4K). Verify against the calibration table in the skill, don't re-derive.
2. **Overshoot watch:** the guard poses (B-84/266, G-63) and the flexed B-76 could read as
   "bodybuilding photo" to nano the way blue-66's flex did. If a take comes back tanned/oiled/
   shredded, re-roll leading with the named-failure context + absolute tan/oil lock (batch-5 recipe).
   ⚠ The whole-frame tan residual LIES on body-local tan (background compensates) — eyeball the
   orig|toned strip on every frame; an out-of-band mean-diff is the corroborating flag.
3. **Mandatory on every frame:** per-channel histogram tone-match to the original · **§4b face
   composite** (standing procedure — measure offsets, don't assume alignment) · garment/background/
   framing/identity QC at zoom · mole + **ear-stud** + necklace check against the original (nano
   deleted a stud and a skin tag on gray-41 through the lock; fix deterministically by compositing
   original pixels, never by re-roll).
4. **Big-smile eye rule (standing):** squinted eyes on big-smile frames get `eye-restore.py` at
   **1.04/1.13**, per photo not per batch (`scripts/eye-restore.py`; the `eyelm` Vision CLI binary
   from the batch-2 scratchpad still works). Many of these picks are open laughs — expect to use it.
5. **Warp:** snug garments only (green retro, black/heather/yellow trunks, white cotton) at k=0.20,
   centre read off a burned coordinate grid (colour-mask detection fails on this set). Skip satin
   Muay Thai, jeans, olive loose shorts, tank-overhang frames, hands-covering-front frames, and the
   4 landscape frames if the frame edge cuts the body.
6. **Deliverables:** `studio-<bg>-<n>_FINAL_PRIMARY.jpg` + `-IG-4x5.jpg` (portrait frames only; the
   4 landscape frames ship full-frame only). IG crop = full width, y-offset from measured head top
   (dark-hair detector, not corner-diff). Source is 4672×7008 — recompute the 4:5 window from actual
   output size, don't reuse prior pixel numbers.
7. **Send before/after strips in chat per wave** and keep pre-rev files in a `v1_backup/`.
