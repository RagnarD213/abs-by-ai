# Local morning brief layout preview

Open `index.html` locally. It is not mounted by the server and is outside `public/`. Every task, message and number is synthetic. No JavaScript, fetches, trackers, third-party assets, forms, authentication or private-data routes are included.

The layout starts with one action, keeps yesterday and opportunities compact, and puts measurement definitions behind expandable details. It adapts to iPad and phone widths. This preview makes no claim that Google sign-in or the daily routine works.
